# Lift Log – Strength & Cardio Tracker
An offline-installable progressive web app based on the streamlined Lift Log tracker.

## Publish on GitHub Pages
Use **Settings > Pages > Deploy from a branch > main > /(root)**.
Your app URL is: https://shamanfarman.github.io/lift-logger/

## Install on Android
Open the link in Chrome, choose **Install app** or **Add to Home screen** from the menu.

## Data
All logged workouts and cardio sessions are saved locally on your device, not on GitHub. Use the built-in **Export backup** / **Restore backup** to transfer history from the previous HTML version. File-based browser storage cannot transfer automatically to a website, and uninstalling or clearing site data can remove entries. Cardio progress uses today plus the preceding six days.
